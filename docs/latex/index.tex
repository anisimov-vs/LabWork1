This project is a C++ program that reads an image from a file, rotates it clockwise and counterclockwise, and applies a Gaussian filter to rotated images. The program then writes the rotated and filtered images to an output directory.

It supports 1-\/, 8-\/, 16-\/ and 24-\/bit both grayscale and colored images. Support of 8-\/bit colored images is limited.\hypertarget{index_autotoc_md4}{}\doxysubsection{\texorpdfstring{Files}{Files}}\label{index_autotoc_md4}

\begin{DoxyItemize}
\item {\ttfamily src/main.\+cpp}\+: The main file containing the main function that reads an image from a file, rotates it clockwise and counterclockwise, and applies a Gaussian filter to rotated images.
\item {\ttfamily \doxylink{bitmap_8h}{src/bitmap.\+h}}\+: The header file containing the structure definitions for the BMP file format and the \doxylink{class_bitmap}{Bitmap} class.
\item {\ttfamily src/bitmap.\+cpp}\+: The implementation file containing the functions for reading, writing, rotating, and filtering images.
\item {\ttfamily \doxylink{util_8h}{src/util.\+h}}\+: Header file containing utility functions for argument parsing, kernel generation, and image manipulation.
\item {\ttfamily src/util.\+cpp}\+: Implementation file containing the utility functions defined in \doxylink{util_8h}{util.\+h}.
\item {\ttfamily Makefile}\+: The makefile for building the program.
